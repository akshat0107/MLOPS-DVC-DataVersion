git add-commit push
#pip install dvc
now we do "dvc init" (creates .dvcignore, .dvc)
now we do "mkdir S3" (creates a new S3 directory)
now we do "dvc remote add -d myremote S3"
next "dvc add data/" (creates data.dvc) then "git add .gitignore data.dvc"
now - "dvc commit" and then "dvc push"
do a git add-commit-push to mark this stage as first version of data.
now make changes to code.py to append a new row in data, check changes via "dvc status"
again - "dvc commit" and then "dvc push"
